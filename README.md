# SLOT 美術字切圖工具

把 Photoshop 做好的一行 SLOT 美術字，自動切成一張一張 PNG，給後製包圖或引擎直接用。

單一 HTML 檔，**雙擊用瀏覽器開就能用，完全離線**，不需要安裝任何東西、不需要網路、不會上傳任何圖片。

---

## 快速開始

1. 用瀏覽器開啟 `slot-glyph-slicer.html`
2. 先按左側「**載入內建測試圖**」，確認工具本身運作正常
3. 把你的去背 PNG 拖進左上角（或在 PS 裡複製後直接 `Ctrl+V` 貼上）
4. 確認偵測框都框對了
5. 選輸出模式、調寬高
6. 按「**匯出 ZIP**」

---

## 兩種輸出模式

| | 等寬（滾分） | 不等寬 |
|---|---|---|
| 用途 | 數字會滾動、跳動的分數 | 靜態顯示的數字 |
| 寬度 | 所有數字畫布同寬 | 各自貼齊自己的寬度 |
| 高度 | 統一 | 統一 |
| 好處 | 滾分時不會左右抽動 | 排版緊湊自然 |

符號（`. , + - x X`）在等寬模式下預設**維持原寬**，不會被撐成跟數字一樣寬。不想這樣就把「符號維持原寬」取消勾選。

## 參數說明

### 2 · 自動偵測

工具用 alpha 通道的直行投影找出每個字的邊界。

| 參數 | 說明 |
|---|---|
| **Alpha 閾值** | 多透明才算「有東西」。陰影太淡會漏抓 → 調低；相鄰的字被陰影黏在一起 → 調高 |
| **最小字間隙 px** | 兩塊像素相距小於這個值就視為同一個字。`i` 的點、`!` 的兩段要靠這個合併 |
| **最小字寬 px** | 比這個窄的碎片直接忽略 |
| **最小像素數** | 像素總數少於這個值的雜點直接忽略。參考線、雜訊靠這個濾掉 |
| **字元順序** | 由左到右依序對應。偵測到的格數必須和字元數一致，不然會整排錯位 |

**偵測不準時的手動修正：**

- 誤判的格子（例如 PS 的參考線）→ 點一下選取，按 `Del` 或「刪除選取」
- 一個字被切成兩半 → 選取左半，按「合併選取＋右鄰」
- 兩個字黏在一起 → 開「分割模式」，在要切的位置點一下

### 3 · 輸出模式

| 參數 | 說明 |
|---|---|
| **等寬字芯寬 px** | 等寬模式下每個數字的核心寬度。預設取最寬的那個數字 |
| **畫布高 px** | 所有字統一的輸出高度 |
| **左右留白 px** | 每個字左右各留幾 px 透明邊。**這就是排版間距**，見下方 Cocos 說明 |
| **全部對齊偶數 px** | 偵測框與輸出畫布的寬高都補成偶數，避免半像素造成模糊 |
| **超寬字自動橫向壓縮** | 比字芯寬還寬的字自動橫向壓進去，不會被裁掉 |
| **全域微調 X / Y** | 所有字一起位移。字帶投影時整排會偏向一側，用這個補回來 |

**最終畫布寬 = 字芯寬 + 留白 × 2**

### 字格微調（逐字）

| 欄位 | 作用 |
|---|---|
| **DX / DY** | 移動這個字在畫布內的位置，不改變畫布大小 |
| **DW / DH** | 直接加減這個字**輸出畫布**的寬高 |
| **寬度 %** | 橫向縮放這個字本身。高度不變，所以基線不會跑掉 |
| **↺** | 這個字的所有微調歸零 |

**基準字工具列** — 選一個字當標準，一鍵套到全部：

- **寬度套用全部** — 等寬模式下把字芯寬設成該字的實際寬度，比它寬的自動壓縮
- **寬度 % 套用全部** — 複製縮放比例
- **框寬高套用全部** — 複製 DW / DH

## 常見情境

### 某個字特別寬，整排被它撐開

例如菱形的 `0` 有 102px，第二寬的只有 88px，等寬模式下每格都變成 102px，整排看起來太鬆散。

**做法：** 把「等寬字芯寬」改成 88，確認「超寬字自動橫向壓縮」有勾選。`0` 會自己壓到 88px，其他字原封不動，整排立刻收緊。

想壓得溫和一點，就把自動壓縮關掉，單獨在 `0` 那列填「寬度 % = 90」，再按「重算建議寬高」。

### 字帶右下投影，整排看起來偏左

trim 的邊界框把投影算進去了，所以右側天生比左側多空間。用「全域微調 X」往右推幾 px 補回來。

### 想確認滾分會不會抽動

開「滾分模擬」。等寬模式下數字應該完全不動；如果會抖，代表某個字的輸出寬度不一致，資訊列會標紅警告。

不等寬模式下整串一定會左右跳（這是必然的，資訊列會算出跳動幅度），所以**會滾分的數字一定要用等寬模式**。

## Cocos 整合

**Cocos 裡的排列一律是「緊貼、不重疊」**，不管哪種做法：

- **BitmapFont（.fnt）** — 靠每個字的 `xadvance` 推進
- **Sprite + Layout(HORIZONTAL)** — 依序貼齊，`spacingX` 預設 0
- **自己算座標** — 你給多少就是多少

所以**左右留白必須切在 PNG 裡**，不然 `0` 和 `1` 會黏在一起。等寬模式尤其要注意：最寬的那個字左右是零留白，相鄰時最擠。建議留白設 2–4 px。

「字格微調」上方那條預覽就是照 `spacingX = 0` 緊貼排列的結果，以那個為準來調留白。

## 輸出內容

匯出的 ZIP 包含：

```
pngs/
  0.png ~ 9.png
  dot.png  comma.png  plus.png  minus.png
  x_lower.png  x_upper.png
sheet.png        合併圖集
sheet.json       圖集座標表
font.json        完整字型設定
```

檔名用語意名稱而不是字元本身，因為 Windows 檔案系統不分大小寫，`x.png` 和 `X.png` 會互相覆蓋。檔名可以在表格裡改，改到重複會標紅並在匯出前擋一次。

### font.json 欄位

```jsonc
{
  "mode": "mono",                  // mono = 等寬, prop = 不等寬
  "monospaceDigitsOnly": true,     // 符號是否維持原寬
  "cell": {
    "coreWidth": 88,               // 等寬字芯寬
    "height": 130,                 // 統一畫布高
    "padX": 2,                     // 單側留白
    "evenSnap": true               // 是否對齊偶數
  },
  "baseline": 118,                 // 基線在畫布內的 Y（從頂端算起）
  "tracking": 0,                   // 預覽用的額外字距
  "globalOffset": { "x": 0, "y": 0 },

  "glyphs": [
    {
      "char": "0",
      "name": "0",
      "file": "pngs/0.png",

      "width": 92,                 // 輸出畫布寬（= advance）
      "height": 130,               // 輸出畫布高
      "advance": 92,               // 排版推進量，緊貼排列時用這個

      "trimmed": { "w": 102, "h": 116 },   // 原始偵測框
      "drawn":   { "w": 94,  "h": 116 },   // 套用寬度% 後實際畫出的尺寸
      "scaleX": 0.92,                       // 寬度%
      "boxDelta": { "w": 0, "h": 0 },       // DW / DH
      "nudge":    { "x": 0, "y": 0 },       // DX / DY
      "drawOffset": { "x": 3, "y": 7 },     // 字在畫布內的左上角座標

      "source": { "x": 30, "y": 40, "w": 102, "h": 116 },  // 在原圖中的位置
      "sheet":  { "x": 2,  "y": 2,  "w": 92,  "h": 130 }   // 在 sheet.png 中的位置
    }
  ]
}
```

`settings` 區塊記錄了這次用的所有參數，下次要重現同一套設定可以照著填。

## 疑難排解

**畫面右上角出現紅色 JS 錯誤訊息** — 把那行字回報，附上你做了什麼操作。

**偵測數量和字元數不符** — 偵測結果區右上角會標紅提示。先檢查有沒有參考線之類的雜物被當成字。

**匯出的 PNG 打不開** — ZIP 用無壓縮格式打包，Windows 內建解壓縮、7-Zip、WinRAR 都能開。如果有問題請回報。

## 開發備註

- 純前端，無任何外部相依。ZIP 打包是自己實作的 store 模式（無壓縮），所以離線也能用
- 圖片處理全在 Canvas API，不會離開瀏覽器
- 所有座標運算以整數 px 為單位，避免子像素模糊
